Resumen
Se hizo un sistema que es capaz de detectar armas (pistol, knife) en imágenes y video. El
pipeline actual integra:
    -​ Extracción de personas con mejora de imagen.
    -​ Detector de armas Faster R‑CNN MobileNetV3-FPN.
           -​ Se ajustó el modelo utilizando scripts de split, aumentación y entrenamiento
                con checkpoints y test.
    -​ App para pruebas sobre archivos y cámara.


1. Módulos
Link de acceso al repositorio: https://github.com/Guanart/procesamiento-imagenes-unlu.


1.1. Módulos activos
Estos son los módulos que están en uso, tanto para el proceso de inferencia desde la app,
como para el entrenamiento y ajuste del modelo.
   -​ person_extraction
          -​ Modelo: YOLOv8n para localizar y recortar las personas detectadas.
          -​ Mejora de imagen: CLAHE + ajuste de brillo (HSV).
   -​ weapon_detection/training
          -​ Modelo: Faster R‑CNN (MobileNetV3 Large FPN).
          -​ Pipeline de datos: split reproducible, aumentación offline (flip, rotación, color,
              blur, ruido), y mejora de imagen opcional (las mismas mejoras que en el
              módulo person_extraction).
          -​ Entrenamiento con AMP, checkpoints cada N épocas (se guarda el .pth) y
              reanudación desde un archivo con los pesos .pth.
   -​ weapon_detection/inference
          -​ detector_pipeline.py recompone las detecciones de armas dentro del
              frame original de la persona, con anotaciones y exportación a video.
   -​ App (apps/weapon_monitor)
          -​ Interfaz web para cargar imagen/video o usar cámara en tiempo real. Ejecuta
              el pipeline de inferencia y muestra resultados.

3. Flujo del pipeline
  1.​ Carga de modelos: YOLO para personas (CPU/GPU automático) y Faster R-CNN
      MobileNetV3 para armas.
  2.​ Detección de personas: por frame, YOLO produce cajas. Se filtra por
      min_person_conf y cada recorte se clampa al frame original.
  3.​ Mejora de recortes: enhance_image aplica CLAHE + ajuste HSV para robustecer
      la señal antes de buscar armas.
  4.​ Detección y clasificación de armas: el recorte mejorado se pasa a Faster R-CNN.
      Cada predicción con score ≥ confidence_threshold devuelve clase
      (knife/pistol), score y caja relativa.
  5.​ Reconstrucción en frame original: las cajas de armas se trasladan usando las
      coordenadas de la persona. Se dibuja la caja amarilla para la persona y roja para
      cada arma detectada, junto con texto PERSON WITH WEAPON.
  6.​ Procesamiento de video: permite frame_skip, registro de progreso y escritura
      H.264 (ffmpeg). Cuenta detecciones totales y soporta callback externo.


4. Datos, entrenamiento y decisiones clave
  4.​ Checkpoints y reanudación
         a.​ Colab Free ofrece sesiones cortas con límites diarios, cuya duración depende
             de la demanda del servicio. Se optó por guardar el modelo cada N épocas y
             el mejor modelo para continuar sin perder trabajo.
  5.​ Early stopping (patience=5)
         a.​ Detiene cuando el val loss deja de mejorar para evitar overfitting y ahorrar
             cómputo.
  6.​ Parser XML multi‑hilo
         a.​ Problema: alta latencia/IOPS bajos en Google Drive → lectura secuencial era
             muy lenta.
         b.​ Primer intento de solución: ThreadPoolExecutor para solapar I/O y acelerar el
             parseo masivo de XML.
          c.​ Mejor solución (la que se utilizó): copiar un ZIP único al disco local de Colab
              desde el disco de Google Drive, y descomprimir (más rápido que copiar miles
              de archivos).
                i.​ El .zip contiene el dataset ya aumentado. Esto ahorra, al menos, 30
                     minutos de procesamiento respecto de corridas anteriores.
   7.​ Mejora de imagen (CLAHE + brillo)
          a.​ Aumenta contraste en recortes y ayuda a la detección de armas pequeñas o
              en sombras.
   8.​ AMP, batch y tamaño de imagen
          a.​ AMP reduce memoria y mejora la velocidad. Input de 320×320 y batch 8–16
              balancean velocidad/VRAM también.

           a.​ O al revés también, el modelo no predijo nada cuando había una pistola.
